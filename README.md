# 墨上工尺谱

墨上工尺谱是面向昆曲工尺谱录入、编辑、排版和导出的免费软件，目前提供 Windows 公测版。

> 本仓库只用于发布官方公测安装包和更新说明；软件源代码目前不开放。软件、墨上基础体及
> 第三方组件的具体使用条件，以下载包内的使用条款和许可说明为准。

## 下载前请确认

- 只支持 Windows 10／11，暂不支持 macOS 或 Linux；
- 必须安装新版 Microsoft Edge（蓝绿波浪图标）或 Google Chrome；
- Windows 10 旧版蓝色 e 图标 Edge 不支持；
- 下载 ZIP 后必须完整解压，再双击“墨上工尺谱.exe”；
- 编辑、保存和导出可离线使用，飞书意见反馈需要联网；
- 当前 EXE 未做可信代码签名，部分安全软件可能提示低信誉。请核对发行页 SHA-256，
  不要关闭安全软件。

请在“发行版／Releases”中下载文件名含“Windows本地网页版-公测版”的 ZIP，
不要下载平台自动生成的 Source code 压缩包，也不要从第三方取得单独 EXE。
